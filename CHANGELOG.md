# Changelog

Results and their interpretation are reported in the manuscript (under review). This log lists code and
repository changes only.

## Unreleased (2026-10-19)

### Changed
- README reduced to the abstract, data source and reproduction instructions.
- Rendered figures and HTML dashboards of the post-v1.0.1 runs are no longer stored; they are regenerated by the
  scripts (`run_experiment.py`, `fleet/plot_fleet.py`, `simulation/*.py`, `figures/*.py`). Machine-readable outputs
  (CSV, JSON, logs) are kept. The archived v1.0.1 results (`results/batch-1_raw`, `results/batch-2_smoothsnv`) are unchanged.
- `figures/make_graphical_abstract.py` added; diagram scripts also export PDF.

## v1.3.1 (2026-10-19)

### Fixed
- `fleet/soak_outages.py`: a gap is classified as a host pause only if the replayer itself stopped publishing for at
  least 80% of it; writes `soak_outage_classes.json`.
- Dataset licence stated as CC0 1.0 (DataCite record of 10.25678/000D3C); the data descriptor article is CC BY 4.0.
- `fleet/edge_node.py`: NumPy 2 compatible scalar conversion (`.item()`); 215-channel docstrings; README command for
  `drift_cleaning_real.py`.

### Added
- `validation/baselines_forward.py`: simple baselines, forward-chaining and purged leave-one-period-out validation,
  VIP scores (`results/validation_v131/`).
- `figures/make_figures.py`, `simulation/plot_drift.py`; `fleet/plot_fleet.py` uses the 215-channel benchmark files.
- `fleet/real_pi/pi_health_readings.txt`: SoC temperature and throttling readings of the physical board.

## v1.3.0 (2026-10-19)

### Fixed
- MQTT reconnection: node, collector and replayer re-subscribe in `on_connect`, use persistent sessions
  (`clean_session=False`) and queued QoS 1 messages; the broker uses persistence (`fleet/runs/x_broker_restart_fixed_600s/`).

### Added
- Long-run test scripts: `fleet/run_soak.sh`, `fleet/soak_schedule.sh`, `fleet/soak_checkpoint.py`,
  `fleet/soak_outages.py`; outputs in `fleet/runs/soak_24h_1hz/`.
- `validation/stats_repeated_cv.py` (repeated CV with the corrected resampled t-test; blocked CV with several CNN
  seeds and moving-block bootstrap), `validation/cnn_tuning_learning_curve.py` (tuned CNN, learning curves),
  `validation/drift_cleaning_real.py` (fouling test on the logged cleaning events). Outputs in `results/validation_v130/`.

## v1.2.0 (2026-10-17)

### Fixed
- Column selection: v1.0.1/v1.1.0 also read `validity_test3_range_scan_absorbance2550_m` (a validity-test field, not
  a spectral channel) as a 216th channel. New opt-in flag `run_experiment.py --spectral-only` keeps the 215
  `scan_absorbance` channels (default unchanged so v1.0.1 stays exactly reproducible). `fleet/export_model.py` and
  `bench_edge.py` use 215 channels.

### Added
- 215-channel runs: `results/batch-6_raw_215ch`, `batch-7_smoothsnv_215ch`, `batch-8_smoothsnv_blocked_215ch`,
  `batch-9_raw_blocked_215ch`; 215-channel benchmarks (`fleet/real_pi/`, `fleet/out_bench_215/`); re-exported model
  `fleet/models/pls_nh4.json`.
- `simulation/robust_sensitivity.py` (Morris/SALib), `simulation/robust_realmatrix.py`, `simulation/export_real.py`,
  `simulation/robust_plot.py`.

## v1.1.0 (2026-10-17)

The default behaviour of `run_experiment.py` is unchanged: re-running the v1.0.1 command reproduces
`results/batch-2_smoothsnv` exactly (`results/batch-3_repro_smoothsnv`).

### Added
- `run_experiment.py --cv blocked`: time-blocked five-fold cross-validation (contiguous periods, blocked inner
  selection), logging date spans and per-fold results; `block_spans.py`.
- `bench_edge.py`: inference benchmark (PLS; 1D-CNN in PyTorch where available and as a pure-NumPy forward pass).
- `fleet/`: Docker/QEMU emulator of a Raspberry-Pi-class edge fleet with Mosquitto MQTT, model export, real-spectrum
  replay, collector, analysis, plots, benchmark matrix and runners, including a runner that adds a physical node
  (`run_fleet_with_real_pi.sh`). Emulated ARM timings are emulated, not Raspberry Pi measurements.
- `simulation/`: physics-informed in-silico UV-Vis + Raman design study (`sim_fusion.py`, `analyse.py`).

### Fixed
- `fleet/gen_compose.py`: quoted environment entries; longer replayer warm-up. `fleet/export_model.py`: replay spectra
  filtered to `valid_data == 1`. `bench_edge.py`: throughput, CPU and size for the NumPy CNN.
