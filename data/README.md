# data/

The raw dataset is **not** committed to this repository (it is CC-BY licensed and large).
Obtain it directly from the primary source.

## Get the data (one file)
1. Open the dataset DOI: https://doi.org/10.25678/000D3C
2. Download **only** the resource named **`2_data.zip`** (UV-Vis spectra + grab-sample labs).
3. Place `2_data.zip` in the **repository root** (next to `run_experiment.py`).
4. Run the experiment; the script auto-extracts and processes it.

Do **not** download `hyperspectral_acquisitions_part01...12.zip` (~16 GB each, image cubes,
not used here). `1_codes.zip` is optional (the dataset authors' own processing code, for
reference only).
